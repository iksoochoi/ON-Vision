# 캡처 시험·튜닝 가이드

## 1단계 시험 순서 (배경차분 모드, 모델 불필요)
1. **카메라 설정 고정** — 실시간 화면에서 노출·ISO·WB를 자동(0)이 아닌 수동 값으로 고정합니다. 자동 노출은 신발이 들어올 때 밝기가 변해 감지가 흔들립니다.
2. **배경 촬영** — 벨트를 완전히 비운 상태에서 `배경 촬영`. 조명·카메라 위치·노출이 바뀌면 다시 촬영합니다.
3. **감지 확인** — 신발을 벨트에 올립니다. 초록 박스가 신발을 감싸고 노란 십자선(중앙)을 지날 때 자동 캡처되는지 봅니다. 터미널의 `[trigger] ...` 로그가 이유를 알려줍니다.
4. **bbox 검수** — `/label`(메뉴에는 숨겨져 있음)에서 노란 점선(자동, 미확인) bbox를 확인합니다.
   - 맞으면 `B`(확인), 틀리면 이미지 위를 **드래그**해서 다시 그리기, 없으면 `삭제`.
   - 오검출(신발 없음)은 `3`(오검출)로 라벨 → 내보낼 때 빈 이미지(negative)로 들어갑니다.
5. **내보내기** — `데이터 내보내기` (또는 `.venv/bin/python -m backend.cli.export_dataset`). `exports/shoe_<시각>/`와 `.zip`이 만들어집니다. 학습 PC에서 `data.yaml`로 YOLOv8n/v6n 학습 후 RVC2로 변환합니다.

## 감지 모드 (`.env`의 `ON_DETECTOR`)
| 모드 | 설명 |
|---|---|
| `background` | 빈 벨트 사진과의 차이로 신발 영역을 찾음. 모델 불필요, 조명이 일정한 환경에서 안정적. |
| `model` | 카메라 안에서 YOLO 실행 (`ON_MODEL_ARCHIVE`, `ON_TARGET_CLASSES`). 학습한 신발 모델을 올릴 때 사용. |

배경차분은 bbox 초안 생성에도 쓰이므로 `model` 모드에서도 `배경 촬영`을 해 두면 모델이 못 찾은 샘플의 bbox를 자동 생성할 수 있습니다.

## 튜닝 (`.env`)
- 빈 벨트에서 박스가 깜빡이면 `ON_BG_THRESH`를 올리고, 신발을 못 잡으면 내립니다.
- 신발이 여러 조각으로 잡히면 `ON_BG_CLOSE`를 올립니다. 작은 물체까지 잡히면 `ON_BG_MIN_AREA`를 올립니다.
- 신발 일부가 화면 밖일 때 캡처되면 `ON_EDGE_MARGIN`(기본 0.01)을 확인하세요. 0이면 잘린 신발도 후보가 됩니다.
- 화면 중앙을 가장 정확히 지나는 프레임을 고르므로 컨베이어가 빠르면 `ON_FULL_FPS`를 올려야 합니다(USB 대역폭 한도 내).

## 선명한 사진 (흔들림 줄이기)
움직이는 신발이 번지는 가장 큰 원인은 노출 시간입니다. 자동 노출은 어두우면 노출을 최대 33ms까지 늘립니다.
- **자동노출 상한** (`.env`의 `ON_AE_LIMIT_MS`, 또는 실시간 화면 → 카메라 설정): 자동 노출을 이 값 이하로 제한합니다. 밝기는 카메라가 ISO를 올려 보충하므로 조명이 충분해야 합니다. 값을 바꿀 때마다 신발을 흘려 보내 번짐과 노이즈를 확인하세요.
- **플리커(안티밴딩)**: 교류 조명에서 자동 노출은 노출을 조명 주기(약 10ms)의 배수로 맞춥니다. 상한을 10ms보다 짧게 하려면 '끔'으로 두세요. 교류 조명에서는 밝기 줄무늬가 생길 수 있어 플리커 없는 직류 조명이 좋습니다.
- **초점 고정**: 화면을 클릭하면 그 지점에 초점을 맞춘 뒤 렌즈 위치를 고정하고 저장합니다. 카메라와 벨트 거리가 일정하면 연속 자동초점보다 안정적입니다. 슬라이더 `초점(렌즈)`을 0으로 두면 연속 자동초점으로 돌아갑니다.
- **선명한 프레임 선택** (`.env`의 `ON_PICK_WINDOW_SEC`, 기본 0.12초): 캡처 순간 가장 가까운 프레임 대신, 그 앞뒤 0.12초 안의 프레임 중 가장 선명한 것을 저장합니다. 카메라마다 따로 고르고, 가까운 프레임보다 5% 넘게 선명할 때만 바꿉니다(신발이 계속 움직이므로 멀리 있는 프레임은 확실히 좋을 때만 씁니다). 기준 카메라는 감지된 신발 영역에서 선명도를 잽니다. 선택 결과는 샘플 JSON의 `sharpness`(저장한 프레임의 점수)와 `pick`(비교한 프레임들의 `[시간차 ms, 점수]`, 바꿨는지 여부)에 남고, 실시간 화면의 작은 사진에 마우스를 올리면 점수가 보입니다. 선명도 점수는 **같은 카메라, 같은 순간의 프레임끼리만** 비교할 수 있습니다. `0`이면 끕니다. 프레임이 더 자주 들어올수록(fps가 높을수록) 고를 후보가 늘어납니다.
- 노출·ISO·WB·상한·초점 값은 카메라별로 `captures/.settings.json`에 저장되어 재시작 후에도 유지됩니다. `.env`의 `ON_AE_LIMIT_MS`는 저장된 값이 없을 때의 시작값입니다. 다른 컴퓨터로 옮길 때 `captures/`를 복사하지 않으므로 새 환경에서는 다시 맞춰야 합니다.

## 디스크 용량 보호
자동 캡처는 사진이 디스크를 가득 채우기 전에 **스스로 멈춥니다.**
- 사진이 저장되는 디스크(`ON_CAPTURES_DIR`가 있는 디스크)의 **사용률이 `ON_DISK_STOP_PERCENT`(기본 90%)에 도달하면** 자동 캡처를 끄고, 공간을 확보하기 전에는 다시 켜지 못하게 합니다(켜려고 하면 이유를 알려줍니다). 사용률은 시스템과 다른 파일까지 모두 포함한 디스크 전체 사용량입니다.
- 신발이 감지되어 저장하기 직전에 확인하고(즉시 멈춤), 신발이 없을 때도 15초마다 확인합니다. 이미 저장 중인 묶음은 끝까지 저장됩니다. 수동 캡처(`지금 캡처`)는 막지 않습니다.
- 공간이 다시 확보돼도 **자동으로 재개하지 않습니다.** 사람이 자동 캡처 스위치를 다시 켜야 합니다(재시작하면 다시 켜진 상태로 시작합니다. 단, 디스크가 한도를 넘은 채라면 OFF로 시작합니다).
- 실시간 화면 상단의 `Disk NN%` 칩으로 사용률을 봅니다(한도 5% 전부터 노란색, 도달하면 빨간색). 칩에 마우스를 올리면 사용량/전체/남은 용량이 보이고, 멈추면 Controls 패널의 Auto capture 카드에 경고가 나옵니다.
- `ON_DISK_STOP_PERCENT=0`이면 멈추지 않습니다. 맥의 디스크 사용률은 APFS의 "삭제 가능한 공간"을 사용 중으로 셉니다. 그래서 Finder에 보이는 여유 공간보다 사용률이 높게 나올 수 있습니다.
